## 1. Option-permutation control

**Question.** How much of \method's B-column MCQ gain survives when the
option contents are cyclically permuted across letters? This separates
"removes the language prior" from "removes the option-letter selection
bias" of Zheng et al. (2024) — the one confound a reviewer has twice
named as uncontrolled.

**Candidate** = the frozen deployed MCQ ladder (malt.py LADDER_MCQ), no
change. Two conditions per row, both generated by THIS script so the
prompt format is identical and only option order varies:
- original: options in the TSV's order.
- permuted: contents cyclically shifted by one letter (A<-B, B<-C,
  C<-D, D<-A), gold letter remapped accordingly.

Views per row per condition (7): default, blank, answer-format real,
answer-format blank, grayscale, strong-blur, center-mask — the full
deployed MCQ view set. Rung-2 routing by image-information confidence
computed from the three corruption views, as deployed.

**Split** = biased VALIDATION MCQ rows, both backbones (Test untouched;
the reviewer's own specification). Rows: all MCQ Biased_Val rows; the
pre-registered readout is the B column (vcf_only + both), with BS
reported for completeness.

**Readout, pre-registered.** For each condition: base accuracy, MALT
accuracy, delta, on B. The control passes if the permuted-condition
MALT-base B delta is within one changed-sample equivalent of the
original-condition delta (rule-13 tie band); partial survival is
reported as the measured fraction. One readout; no retuning; whatever
it says goes in App. C next to the image-free controls.

**Detector** = none. **Calibration** = none (frozen constants).
**Kill rule** = n/a (control, not candidate); an unfavourable result is
reported as-is.

## 2. Batched wall-clock

**Question.** Does the ~0.7x wall-clock claim survive batched serving,
where SCI's independent branches batch into one round trip and the
ladder cannot?

**Measurement.** Qwen2-VL-7B (primary backbone), 32 biased-Val samples,
median of 5 repetitions per point, deployed image budget:
- SCI5: one batched forward, batch=5 (its five views).
- SCI7: one batched forward, batch=7.
- MALT mean path: sequential stage timing — batch=1 (s0), then batch=3
  (rung 1 views) at the measured f1 rate, then batch=3 (rung 2) at f2;
  reported as t1 + f1*t3 + f2*t3 with the biased-split rates.
- MALT worst path: t1 + t3 + t3.

Reported in App. A as a sensitivity row; the sequential-pricing claim
in the abstract is revised to whatever this measures. LLaVA excluded
(batched multi-image preprocessing differs; stated).

## Result summary

Permutation, B rows: Qwen2 base 10.98 -> 23.17, MALT 30.49 -> 33.74,
delta +19.51 -> +10.57 (54% survives). LLaVA base 12.61 -> 21.22, MALT
26.05 -> 30.04, delta +13.45 -> +8.82 (66% survives). BS survival
60%/75%. MALT's absolute accuracy rises under permutation on both
backbones, so the corrector does not exploit the arrangement; the
control cannot separate letter bias from regression off an
error-selected subset, and the paper says so.

Batched clock (Qwen2, uniform reduced budget): SCI5 1.07 s, SCI7 1.92 s
per sample as one batched round trip; MALT sequential mean path 0.71 s
(0.37x SCI7), worst path 1.02 s. Batch-of-7 at the deployed budget
needs ~41 GiB and does not fit on one A100-80G.

## Amendment — clock image budget (2026-07-22, before any readout)

Batch-of-7 at the deployed image budget requires ~41 GiB of attention
workspace and OOMs on one A100-80G — reported as a finding (SCI7's
"one batched round trip" needs more than one 80G device at this
budget). The clock is re-run at a uniform reduced budget (max 1024
patches) for every arm, so the reported ratios are budget-matched.

## Amendment — image cap in the permutation run (2026-07-22)

qwen_vl_utils fails to cap extreme-aspect images (a single view OOMed at
42 GiB); images above ~8192 patches are pre-shrunk before both
conditions. The two conditions share the identical image, so the
orig-vs-permuted comparison is unaffected. 42 rows were already
checkpointed before the amendment; they used only non-extreme images
(the run died on the first extreme one) and are kept.
